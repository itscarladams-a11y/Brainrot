# Brainrot Academy v0.16.8 — Testing Polish

- Wrong answers now show the correction and explanation until the learner taps Next Question or See Results. Correct answers keep their fast arcade rhythm.
- Parts of Speech lessons require at least 75% to count as complete; the result screen clearly invites another attempt after a lower score. Mixed mastery uses the same threshold.
- Progress reports now assign daily activity to the learner's local date, and an unavailable local save shows a visible warning.
- The offline worker only returns the home page for page navigations, ignores unrelated requests, and caches successful app assets without substituting HTML for failed media.
- Added a lockfile, reproducible npm installation, a Codespaces container and Android SDK setup, and a current GitHub Actions test APK workflow.
- Updated the build identity, Android version code, documentation, and offline cache to v0.16.8.
