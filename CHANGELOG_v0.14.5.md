# Brainrot Academy v0.14.5 - Parent PDF Progress Reports

## Highlights
- Added an on-device **Download PDF Report** feature to the Parent Dashboard.
- Parents can enter a student name, choose Last 7 Days, Last 30 Days, or All Time, and export the currently selected grade view.
- Reports include activity totals, accuracy, quiz summary, difficulty usage, subject performance, current mastery, recommendations, and recent sessions.
- Android APK builds now include a native PDF save bridge that writes reports to **Downloads/Brainrot Academy**.
- Browser/PWA builds fall back to a normal local PDF download.
- Future progress records now store grade-specific daily activity and Normal/Hard/Extreme session difficulty for better reporting.

## Privacy
- PDF generation is local. No student account or cloud upload is required.
